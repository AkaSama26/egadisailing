# SEO Priority 3 - Piano operativo pagina per pagina

Snapshot: 2026-05-23. Questa cartella trasforma la strategia SEO in brief implementabili per ogni pagina canonica del sito Egadisailing.

## Obiettivo
- Far rankare homepage e pagine esperienze senza cannibalizzazione.
- Assegnare a ogni URL un intento primario chiaro.
- Applicare la strategia a IT/EN/ES/FR/DE con una sola scheda canonica per pagina.
- Usare frequenze keyword come guida editoriale, non come densita' meccanica.

## Come usare questi file
1. Leggere `ORCHESTRATOR.md`.
2. Usare `CANNIBALIZATION-MATRIX.md` per verificare che una pagina non stia rubando l'intento a un'altra.
3. Aprire il brief pagina in `pages/`.
4. Applicare interventi in ordine: title/H1/intro, blocchi, FAQ, internal links, schema.
5. Passare dal controllo finale dell'orchestrator.

## Regole non negoziabili
- Marettimo resta informazionale: non creare promessa commerciale di tour/grotte Marettimo.
- La landing skipper usa "con skipper"; non usare bareboat o senza skipper.
- `/esperienze` e' la money page generica. La homepage deve restare brand/trust.
- `/prenota` e' transazionale, non hub commerciale.
